# Interface: EditorGuideConfig

Settings controlling the guides displayed in the editor canvas.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| `showBleed?` | `boolean` | Whether the editor canvas renders the bleed guide. **Default** false, except `true` when [ExperienceVariant.PRINT](../enumerations/experience-variant.md#enumeration-member-print) is the active variant. |
| `showMargins?` | `boolean` | Whether the editor canvas renders the margin guide. **Default** false, except `true` when [ExperienceVariant.PRINT](../enumerations/experience-variant.md#enumeration-member-print) is the active variant. |
| `showRulers?` | `boolean` | Whether the editor canvas renders rulers. **Default** false, except `true` when [ExperienceVariant.PRINT](../enumerations/experience-variant.md#enumeration-member-print) is the active variant. |
