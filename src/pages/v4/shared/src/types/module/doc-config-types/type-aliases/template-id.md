# Type Alias: TemplateId

```ts
type TemplateId = string;
```

Adobe Express template identifier (URN string, e.g.
`urn:aaid:sc:VA6C2:…`). A distinct type so tooling (test-app widget map,
generated JSON Schema `$ref`) can select a richer UI widget automatically.
